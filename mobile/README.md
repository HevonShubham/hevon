# HEVON Mobile

Expo React Native app for iOS and Android.

## Run

```bash
npm install
npm start
```

Open the QR code with Expo Go, or use `npm run ios` / `npm run android` with a configured simulator.

## Current scope

- Product introduction and current bottle artwork
- Future flavour selection and vote submission
- Early-access link to hevon.in

Vote submissions post to the existing HEVON website form endpoint.
